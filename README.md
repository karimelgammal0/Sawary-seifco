# داشبورد مشروع صواري — متابعة المقايسة والمستخلصات

لوحة متابعة تفاعلية لمشروع صواري (٦ أبراج سكنية) — تتبع المقايسة، المستخلصات،
التكاليف والتحليلات لكل المقاولين.

## المحتوى
- `index.html` — التطبيق بالكامل (ملف واحد، بدون أي اعتماديات خارجية عدا الخطوط).

## النشر
منشور عبر **GitHub Pages** من فرع `main` / المجلد الجذر (root).

الرابط بعد التفعيل:
`https://<username>.github.io/sawary-dashboard/`

## التحديث
استبدل `index.html` بالنسخة الجديدة ثم:

```bash
git add index.html
git commit -m "تحديث بيانات الداشبورد"
git push
```

التحديث يظهر على الموقع خلال دقيقة تقريبًا.
